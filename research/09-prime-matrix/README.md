# Prime matrix

**When:** 17 Aug 2025

Numbers 1 … N² in an N × N grid with composites zeroed, and the eigenvalues of that matrix.

**Verdict:** Even and odd N differ because of parity: for even N every even column is empty apart from the 2, so half the eigenvalues are 0.
