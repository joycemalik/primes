# primes

**Prime numbers as an interference of waves, and what that has to do with the Riemann hypothesis.**

Live site: **[primes.joycemalik.com](https://primes.joycemalik.com)**

[![Where the Waves Go Quiet](.github/preview.jpg)](https://primes.joycemalik.com)

Between June and September 2025 I tried many ways to "break or prove" the Riemann hypothesis. I started from one intuition: *primes are the silence left behind when the waves of smaller primes interfere.* This repository holds all of that work: about 170 scripts, 15 notebooks, 1,100+ figures, MIDI songs and animations, organised by idea. It is also told as a film, *Where the Waves Go Quiet*, which shows each experiment working and re-tests each claim honestly.

**Short answer:** nothing here proves or disproves RH, and no computation can. The prime wave turns out to be exactly the Sieve of Eratosthenes. The intuition becomes exact in one place: Riemann's 1859 explicit formula, where the waves come from the zeros of ζ(s). The site shows that formula live.

Every script starts with a short header comment giving the same information. File names keep their original numbers (`prime01_…`, `v01_…`, `07_…`), so the order of the experiments is preserved.

## The site

The site is a scroll film in six acts, narrated in my own hand, in the order I actually worked. Every frame is computed live in the browser, and the soundtrack is generated by the mathematics itself:

- a pulse steps through the integers: primes ring, composites tick, and the gaps between primes become the rhythm
- in Act I you hear the waves of 2, 3, 5, 7 … as a chord that thickens as more primes join
- in Act IV the 3D prime walk plays as a melody, each gap the interval to the next note
- in Act V the zeta spiral falls silent at every zero, and the zeros of ζ become tones that rebuild the prime staircase through Riemann's explicit formula
- in Act VI a riser climbs while one million numbers are tested against Robin's inequality

Press *Play* (or the space bar) to let it run, or simply scroll. `?solo=s-zeta:0.5` renders a single still of any scene.

Run it locally: open `site/index.html`, or run `python -m http.server` inside `site/`.

## Running the research code

```
python -m venv .venv
.venv\Scripts\activate          # Windows   (source .venv/bin/activate on macOS/Linux)
pip install -r research/requirements.txt
```

Most scripts run on their own, e.g. `python research/01-prime-wave-sieve/detectors/prime_wave_detector.py`. A few print emoji, so on Windows set `PYTHONIOENCODING=utf-8`.

## Deploying to Vercel

Import this repository in Vercel. The root `vercel.json` publishes the `site/` folder with no build step, so no settings are needed. Then add the domain `primes.joycemalik.com` under Project → Settings → Domains, and create a DNS record `CNAME primes → cname.vercel-dns.com` at your DNS provider.
